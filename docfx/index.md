# Microsoft.VisualStudio.SDK.Analyzers

Roslyn analyzers and code fixes for Visual Studio extension authors.

Use the [Microsoft.VisualStudio.SDK.Analyzers NuGet package](https://www.nuget.org/packages/Microsoft.VisualStudio.SDK.Analyzers)
to find common Visual Studio extensibility issues early, with guidance and automatic fixes where available.
